# Arty Social

Social channel automations for Interio Arty. Every channel pushes its leads into one central CRM.

| Folder | Status |
|---|---|
| `instagram/` | Live. AI lead-qualification DM assistant "Arty" (Vercel + Supabase). See its README. |
| `whatsapp/` | Planned |
| `facebook/` | Planned |

Each folder deploys on its own (set the Vercel project root directory to that folder).
